# Личный штаб — приложение

Устанавливаемая PWA-версия «Личного штаба»: планы, достижения, анализ, финансовые цели,
чек-ин дня и личный кабинет. Работает офлайн, данные хранятся на устройстве.

## Что внутри
- отдельная иконка на телефоне/ПК, открывается без адресной строки браузера;
- service worker кэширует интерфейс — работает без интернета после первого захода;
- все кнопки (Добавить / удалить / отметить чек-ин / внести взнос) сохраняют
  данные локально (localStorage), поэтому ничего не пропадает при перезапуске.

## Как установить
1. Загрузите папку целиком на любой статический хостинг (GitHub Pages, Netlify,
   Vercel, обычный HTTPS-хостинг) **или** откройте `index.html` прямо в браузере
   для локального использования на одном устройстве.
2. На телефоне откройте сайт в браузере → меню → «Добавить на главный экран» /
   «Установить приложение». На ПК — иконка установки появится в адресной строке
   Chrome/Edge.
3. Готово — иконка «Штаб» появится как обычное приложение.

## Защита доступа (важно!)
Сейчас при открытии приложения показывается экран блокировки:

- **При первом запуске** вы придумываете код доступа из 6 цифр и получаете
  **одноразовый код восстановления** — его нужно один раз сохранить (менеджер
  паролей / заметки). Он пригодится, если забудете основной код: после его
  использования сразу нужно будет задать новый код.
- **При следующих открытиях** приложение просит ввести этот код. Код хранится
  на устройстве не в открытом виде, а как SHA-256 хэш.
- Разблокировка держится до закрытия вкладки/приложения (по сессии).

Это **рабочая локальная защита уже сегодня** — блокирует случайный доступ,
если кто-то возьмёт телефон/ноутбук в руки. Но это не серверная авторизация:
человек с самим файлом приложения теоретически может обойти проверку в коде
браузера. Это нормально для личного use-case, но не для чувствительных паролей
(для них — Bitwarden/1Password, есть заметка в разделе «Доступ»).

### Telegram-бот / QR / биометрия (Passkey) — на будущее
В экране входа есть блок «Другие способы входа» — кнопки для Telegram, QR и
Face ID/отпечатка уже готовы на фронтенде. Они ждут бэкенд (`server.js`) с
Telegram-ботом, который выдаёт настоящую серверную сессию. Пока `server.js` не
запущен, эти кнопки честно показывают сообщение «появится после запуска
server.js» — ничего не ломается, просто ждут подключения. Когда бот будет
развёрнут (Node.js + HTTPS + переменные окружения бота), эти методы заработают
без изменений в интерфейсе.
